# Intermediate-audience review

Audience: readers know the field's basic terms and mechanisms, but need the project's implementation choices explained. Standard terminology does not require a glossary aside. Project-specific semantics, notation legends, representation choices, and limits still require context.

- **OJaml:** Removed explanations of lexing, ASTs, source spans, unification, closures, and basic ML syntax. Replaced them with binder-span precision, pruned type references, module ascription and compile-time namespaces, uniform i32 representation, ordered collection patterns, and generated closure-call arities. Factorial remains a syntax example. Removed repeated integer/string mismatch examples and introductory explanations of exhaustiveness.
- **LiveBoard:** Removed definitions of WebSocket, authoritative state, httpOnly, TTL, and inverse operations, plus the elementary viewport arithmetic. Combined repeated shape/schema explanations. Retained server-derived inverses, batch ordering, optimistic echo suppression, snapshot recovery, connection-count presence, and commit-rejection cleanup.
- **Hearth:** Removed primers on saturation, aliasing, transfer curves, DC offset, hysteresis, and wet/dry terminology. Combined repeated macro and flux explanations. Retained local ADAA evaluation, bias subtraction, direction-dependent memory, bounded detector control, full-path listening, and generated-device ownership.
- **JaggerScript:** Removed repeated accounts of counters retaining fields and basic constructor/return/break behavior. Focused on parser normalization, heap-backed field mappings, receiver restoration, control-signal propagation, and the boundary between lightweight editor checks and runtime enforcement. Counter illustrates those structures rather than supplying the article's premise.
- **AIXC:** Removed tokenizer and entropy-coding definitions, elementary rank explanations, repeated wrong-guess traces, and explanations of what a compression ratio means. Retained the reconstruction invariant, independent coding layers, predictor reproducibility, exact token round trips, and complete deployment costs.
- **GeneticTS:** Removed definitions of genome, population, rollout, and hit rate, elementary crossover arithmetic, and repeated descriptions of stored-path playback. Retained world isolation, score discontinuity, rank-biased selection, separate mutation/reset exploration, seed dependencies, and solved-streak policy.
- **Rengine:** Removed scene-graph and local/world definitions, basic frame-rate-independent motion explanations, and repeated accounts of component order. Kept composition conventions, anchor instrumentation, sequential state updates, the integration's 32 ms cap, renderer differences, and snapshot/UI ownership.
- **TSXLight:** Removed definitions of TSX, JSX, receiver, and DOM, plus repeated accounts of separate users and counter increments. Kept custom factory output, renderer-context selection, scoped callback lifetimes, dispatch sequencing, explicit state retention, and connection isolation.

The source manuscripts remain in documentation. Existing code examples, visuals, equations, and deep links remain available. The essays retain explanations of mechanisms particular to each project; familiarity with a field is not assumed to imply familiarity with this implementation.
